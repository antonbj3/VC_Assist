# VC Assist

LLM-assistent för **Visual Components 4.10 Premium**, med sluten loop mot en mjuk-PLC.

Bygger scenen, genererar styrkod i strukturerad text, kör den mot scenen,
och låter **scenen** avgöra om sekvensen och timingen fungerar.

Ärver observations- och grinddoktrinen från Isaac Assist
(`Omniverse_Nemotron_Ext`): mät aldrig om, låt ögat fälla domen,
grinden parsar ögats egen utdata.

## Kärnprincip

Generatorn behöver inte vara perfekt. **Grinden** avgör vad som släpps igenom.
Ingenting levereras förrän ögat har sett att det fungerar i tid.
